# 실행 프롬프트 용어·환경 독립성 계약 — V1

- 적용일: 2026-11-12 KST
- 개정: r0002 / 2026-11-14 KST — 역할별 표준 용어와 모바일 Agent/MCP 실행 경계 추가
- 범위: CoWork 전체 Skill, Job-list 요청, Skill-Updater 전달물, L1 Knowledge/Code Analyzer/Doc Converter 오케스트레이션, Agent MCP 질의, Linux/Windows 실행 인계 및 새 대화에 제공하는 복사용 프롬프트.
- 성격: 사용자가 이전부터 요청한 **기본 작성 규칙**을 반복 확인 없이 적용. 실제 설치·모델 호출·운영 변경을 승인하거나 실행하지 않는다.

## 기본 규칙

1. **실행용 프롬프트 본문에는 망·위치 구분 표현인 `사내`, `사외`, `내부망`, `외부망`을 기본적으로 쓰지 않는다.** 이 구분이 필요하다면 `실행 환경`, `협업 환경`, `대상 호스트`, `실행 호스트`, `작업 저장소`, `배포 저장소`, `현재 설치본`, `승인된 연결`처럼 역할/권한 중심으로 서술한다.
2. 사용자가 특정 망 구분을 프롬프트에서 **명시적으로 요청했거나**, 실질적 실행·보안 통제상 위치를 구분하지 않으면 오류가 발생하는 경우에만 좁은 예외를 허용한다. 예외가 필요하면 지리적 수식어보다 명시적 호스트/저장소/승인 정책의 실제 ID를 우선한다.
3. 실행용 프롬프트에서는 외부 협업 서비스 브랜드·URL·경로·토큰 또는 인증 의존성을 불필요하게 노출하지 않는다. 단 실제로 필요한 승인된 실행 계약의 정확한 경로/버전/Job ID는 보존한다.
4. **협업 정책·상태 설명과 실행용 프롬프트를 구별한다.** 정책 문서에서 환경 역할을 설명하는 것과 실행 프롬프트 본문에 위치 수식어를 강제하는 것은 별개이다.
5. 요청을 재작성·수정하면 **기존 WritingBlock 전체를 같은 ID로 교체**하고, 신규 산출물에서 같은 표현이 재발하지 않도록 본문/제목/주석/결과 형식을 검토한다.
6. 이미 배포된 불변 ZIP이나 실행 이력은 문체 변경만을 이유로 자동 재게시·재실행하지 않는다. 다음 승인된 신규 버전/프롬프트부터 적용한다.

## 역할 기반 표준 용어 (L1 지식·스킬 협업)

| 표준 명칭 | 책임과 정보 경계 |
|---|---|
| **설계 GPT** | 전체 L1 지식 설계·스킬 간 역할·정합성·리뷰 판정. 허용된 설계 문서/비민감 피드백을 확인하며 Linux 실제 실행을 직접 검증했다고 주장하지 않음 |
| **업무 GPT** | 실행 결과 원문을 전달받아 검토하고 Knowledge Updater·프로젝트 맥락·지침을 관리. 별도의 파일·코드·MCP 직접 접근을 가정하지 않음 |
| **실행 LLM** | 승인된 스킬/도구로 분석·격리 시험 및 결과 보고. 실제 실행·자체시험과 독립 리뷰를 구분 |
| **모바일 Agent** | 승인된 Linux MCP 인터페이스로 Work/Job 요청·상태 및 결과 조회를 연결. MCP 호출, 호스트 실제 실행, 영수증 및 지식 게시의 성공은 각각 별도 확인 |

- 위 용어는 **역할 표기**이고 특정 모델, 연결 권한, 배포 위치, 실제 호출 지원 여부를 보장하지 않는다. 필요 시 `OpenCode`, `Claude Code`, `job-list`, `Linux MCP`처럼 도구 실명도 병기한다.
- 모바일 Agent → Linux MCP → `l1-fix-workflow` (Work 검색·재개), 신규 Job-list 필요 시 조건부 `skill-updater` **1회 요청** → 승인된 Job 실행/결과 조회는 **사용자 보고 운영 경로**다. 실제 API·권한·트리거·실행 영수증 및 현재 E2E 성공은 해당 호스트 증거로 확인 전까지 `NOT_VERIFIED`.
- `skill-updater`는 승인된 ZIP 설치·검증 소유자이며 Job 스케줄러가 아니다. 1회 **요청**, 실제 **실행**, 패키지 **적용**, Job **활성화**, 최종 **분석 결과**는 서로 다른 상태다.
- 원본 코드·로그·상세 MSC 및 비허용 정보를 협업용 저장소 또는 전달물에 자동 포함하지 않는다. 과거 문서·파일명은 감사 추적을 위해 변경 없이 보존한다.
