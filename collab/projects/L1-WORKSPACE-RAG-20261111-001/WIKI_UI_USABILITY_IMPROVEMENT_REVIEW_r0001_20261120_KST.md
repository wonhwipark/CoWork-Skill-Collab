## 1. 결론과 적용 순서

현행 위키형 화면의 좌측 탐색·중앙 본문·우측 목차 구조와 보라색 강조는 유지할 가치가 있다. 기존 화면 이미지에서 본문과 제목의 계층은 분명하다. 우선 개선할 부분은 장식 추가보다 읽던 위치와 탐색 맥락 유지다. 여러 담당자가 문서→MSC→관련 지식을 반복해서 오갈 때 효과가 클 것으로 예상한다. 실제 사용자 작업 시간 개선은 아직 측정하지 않았다.

## 2. 기존 P1 수정방안 재검토

### UX-P1-01 — MSC 넘침 안내: 수용

- 실제 가로 넘침이 있을 때 MSC 바로 위에 ‘오른쪽으로 스크롤해 더 보기’ 같은 텍스트를 표시한다. 6명/12명이라는 인원 수만으로 표시 여부를 결정하지 않는다.
- 오른쪽 끝에서는 오른쪽 안내를 지우고, 왼쪽에 남은 내용이 있으면 왼쪽 이동 가능 상태를 알린다. 확대·축소·폭 맞춤·화면 크기 변경 후 다시 계산한다.
- 그라데이션으로 participant나 메시지를 가리는 방식보다 텍스트 안내를 우선한다. 숨어 있는 participant 수는 실제 계산 근거가 없으면 표시하지 않는다.
- 12명 MSC를 기본적으로 화면 폭에 강제 축소하면 글씨가 작아질 수 있으므로, 읽을 수 있는 기본 배율과 사용자가 선택하는 ‘폭 맞춤’을 구분한다.
- 합성 SVG의 안내 개선은 실제 doc-converter MSC 연동·격리 검증을 대신하지 않는다.

### UX-P1-02 — CSS 중복 정리: 수정 수용

- 현행 style.css에는 기본 규칙·화면 폭별 규칙 뒤에 Readability baseline과 화면 폭별 덮어쓰기가 추가되어 있다. 미래 수정의 유지보수 위험이며, 현재 화면이 깨졌다는 판정은 아니다.
- 공통 토큰·기본 규칙·화면 폭별 규칙을 한 순서로 정리하고 겹치는 선언을 합친다. 주석만 추가하는 수준으로 끝내지 않는다.
- 실제 계산된 본문 16px, H2 22px, H3 17px과 현재 여백·색상·스크롤 범위를 보존한다. 인쇄·동작 줄이기 규칙도 확인한다.

## 4. 화면 스타일·가독성 판단

- 유지: 흰색 중심 배경, 제한된 보라색 강조, 16px 본문, 분명한 제목 계층, 핵심 요약 박스. 전체 재디자인보다 현행 일관성을 보존하는 편이 적절하다.
- 개선 후보: 좁은 화면의 담당자·일자·합성 예시·읽기 전용 정보를 의미별 두 줄로 묶고, 검증 상태는 색상과 짧은 글자를 함께 사용한다. 원본 경로·긴 revision은 상세 영역에 두되 중요한 상태를 숨기지 않는다.
- 현재 검색 결과에는 모듈·문서 종류·상태가 이미 있으므로 같은 정보를 새 기능처럼 중복 추가하지 않는다. 문맥·경로와 읽던 상태 유지가 추가 가치다.
- 기존 UX-P2-01/02는 보류 유지. 320px 이미지에서 byline이 촘촘한 점은 확인했지만, 이를 위해 필수 상태를 제거하거나 모든 탐색 구조를 바꾸지는 않는다.
- 명도 대비 수치·색각 조건·실제 보조기기 동작은 이번 검토에서 측정하지 않았다. 접근성 적합 판정을 내리지 않는다.
