05 · 가장 중요한 왕복 인터페이스

사내 변경을 사외 설계에 반영하는 MCP 피드백

기존의 긴 Markdown 수동 전달 대신, **사내에 남겨야 할 데이터와 외부로 내보낼 수 있는 메타데이터를 분리**합니다. 이 인터페이스는 제안이며 현재 구현·연결되지 않았습니다.

내부 전용① 변경 결과 원본코드·로그·상세 원인·실제 시험 근거. 사내 저장만
사내 변환② 추상 Enum변경 유형·사유·호환성·시험 수준 코드만 추출
엄격 검증③ Schema + DLP추가 필드·자유 텍스트·금지 데이터 제거/거부
Fail closed④ 반출 승인정확한 payload·대상·만료·권한을 독립 검증. 없으면 0회 송신
미구현⑤ MCP submit승인된 outbound 경로가 실존할 때만 전송
수신측⑥ 영수증·중복 차단동일 ID 재전송 방지, 불명확하면 상태조회
사외 GPT⑦ 설계 델타 판정변경된 공통 계약만 업데이트, 실제 코드 미수신
전송 후보 예시
subject=WORKFLOW_INTEGRATION
change_kind=CONTRACT_GAP
reason_code=INTERFACE_MISMATCH
test_state=NOT_RUN
decision_requested=REVISE_CONTRACT
금지·차단
소스/상세 MSC/Jira·CL/사내 경로/토큰/사내 조직 정보/원본 로그 외부 전송 금지. MCP 서버나 전송 권한이 미확인이면 NO_EXPORT. 외부 PRIVATE GitHub도 사외로 취급.
