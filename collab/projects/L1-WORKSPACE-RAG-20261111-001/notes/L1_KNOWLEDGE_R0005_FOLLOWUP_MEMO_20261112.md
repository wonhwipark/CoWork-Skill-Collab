## 3. 긴 보고서를 옮기지 않는 전달 방식

상세 보고서·코드·MSC·로그·내부 경로는 사내에 보관한다. 사내 정책상 반출이 허용된 범주형 요약만 전달한다. 허용 여부가 불명확하면 외부 전송하지 않는다.

전달이 허용되면 아래 요약을 복사하거나 말로 읽으면 된다. 원문 전체를 타이핑할 필요는 없다. 이 요약은 후속 보완 방향을 판단하는 자료이며 설치본·통합시험 검증 증거를 대체하지 않는다.

```text
기준: r0005
조사: 완료 / 부분 / 미완료
컨버터 재사용: 문서확인 / 연결설계 / 실행확인 / 미확인
기타 스킬 연동 누락: 없음 / 있음 / 미확인
중복 구현: 없음 / 있음 / 미확인
필요 보완: 없음 / 문구 / 연결설계 / 추가조사
기존 지식·메타데이터 쓰기: 없음 / 있음 / 미확인
실행시험: NOT_RUN / PASS / FAIL / SKIP (실행했다면 격리·사내 환경 구분)
```

'실행확인'은 해당 호출의 결과와 근거가 있을 때만 선택한다. 문서 참조만 확인한 경우 '문서확인'으로 보고한다. 세부 사유가 필요하면 공개 가능한 범주형 이유만 한 문장 덧붙인다.
