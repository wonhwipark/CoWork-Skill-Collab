## 6. 남은 위험
1. **구독 사용량 한도**: 이 계정은 구독(Pro) 인증이다. 한도에 걸렸을 때 CLI의 오류 형식을 관찰하지 못했다(실제 호출이 필요해 미실행). 현재는 일반 CLI 실패로 처리되어 해당 요청이 FAILED로 종료되고 새 revision이 필요하다. 형식을 한 번 확인하면 '재시도 가능한 대기'로 분류할 수 있다. 일일 횟수 상한을 낮게 두면 한도에 닿을 확률을 줄인다.
2. 로그인은 확인 시점과 호출 시점 사이에 만료될 수 있다(짧은 틈). 이 경우 일반 실패로 처리된다.
3. PC 전원·네트워크·절전 상태는 소프트웨어로 보장할 수 없다. 정지 감지는 알림일 뿐 복구가 아니다.
4. 정지 감지는 notifier가 살아 있어야 동작한다. notifier와 감시기가 같은 PC에서 함께 멈추면 알림이 없다. 외부 감시(예: 휴대폰에서 GitHub 결과 파일 유무 확인)는 별도다.
5. 같은 요청에 대한 로그인 알림은 요청당 1회라서, 같은 요청이 두 번째 만료를 겪으면 알림이 반복되지 않는다.
6. 정지 표지는 쓰기 권한자 누구나 만들 수 있으므로 악의적 사용자가 리뷰를 계속 막을 수 있다(가용성 위험이며 보안 위험은 아님). 저장소 쓰기 권한자는 신뢰 범위 안에 있다는 전제이고, 정지 해제는 파일 삭제로 충분하다.
